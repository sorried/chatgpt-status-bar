# architecture

`src/session.*` reduces rollout records and app-server notifications to session state. observed and controlled sessions use the same thread id, with server events taking precedence for controlled sessions. total reported tokens and model context capacity are separate values; cumulative tokens are not used to calculate context occupancy.

`src/watcher.*` reads recent local JSONL files incrementally. partial trailing records wait for the next poll. initial reads are bounded to 512 KiB per file plus its metadata header; oversized records are skipped. a scan batches state changes so historical transitions do not open a cascade of notifications. silent observed work becomes unknown after five minutes. the file format is internal and has no compatibility guarantee.

`src/codex.*` starts a separately installed Codex executable with the fixed argument `app-server`. JSON-RPC messages travel through stdin/stdout, with no TCP listener. executable arguments are not shell-expanded. initialization completes before any other request. changing the selected home only sets the child's `CODEX_HOME`. the app does not read `auth.json`, refresh credentials or edit `config.toml`.

`src/app.*` owns the monitor, settings, tray and floating window. new tasks use the user's selected project and model, `approvalPolicy: untrusted`, and `sandbox: workspace-write`. individual approvals default to deny. task text, commands and other remote content are rendered as plain text. unsupported server requests receive a JSON-RPC method-not-found error. this client does not implement automatic execution or approvals.

`src/mascot.*` draws original companions with QPainter. a timer animates visible companions only. there are no downloaded sprites or web assets.
