## settings and desktop builds

- redesigned settings with a glass-style sidebar, grouped controls and animated switches.
- separate light and dark materials, readable content surfaces and reduced transparency.
- existing language, notifications, appearance, startup and Codex settings remain available.
- Linux x64, Windows x64 and universal macOS bundles, with SHA-256 checksums.
- compilation, core tests, settings interaction tests and packaged startup checks run in GitHub Actions.

Linux: extract the archive and run `bin/gpt-status-bar`. Windows: extract the entire ZIP and run `bin/gpt-status-bar.exe`. macOS: extract and open `gpt-status-bar.app`.

the glass appearance is drawn in Qt. it is inspired by Apple's design language; it does not use Apple's native Liquid Glass renderer on Linux or Windows. builds are unsigned.

## настройки и сборки

- новые настройки со стеклянной боковой панелью, сгруппированными строками и анимированными переключателями.
- светлая и тёмная темы, читаемые области содержимого и уменьшение прозрачности.
- сохранены язык, уведомления, внешний вид, автозапуск и подключение Codex.
- готовые архивы для Linux x64, Windows x64 и macOS universal, с контрольными суммами SHA-256.
- GitHub Actions компилирует приложение, запускает тесты ядра и настроек, проверяет запуск готовых сборок.

Linux: распакуй архив и запусти `bin/gpt-status-bar`. Windows: распакуй ZIP целиком и запусти `bin/gpt-status-bar.exe`. macOS: распакуй и открой `gpt-status-bar.app`.

стеклянный интерфейс нарисован средствами Qt по мотивам дизайна Apple. в Linux и Windows не используется нативный движок Apple Liquid Glass. сборки не подписаны.
