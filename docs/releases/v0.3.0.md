## compact activity card

- replaces the dashboard window with a compact black card that opens from the status panel.
- hover to inspect the task and current activity, click to pin, close to collapse.
- shows plans, recent actions and agent counts only when Codex provides them.
- approval requests for tasks launched here appear in the card with allow-once and deny controls.
- starts with only the status panel and tray icon. preview mode remains explicitly labelled as synthetic.
- keeps the glass-style settings from v0.2.0.

Linux x64, Windows x64 and universal macOS bundles are built and tested in GitHub Actions. archives include Qt dependencies and have SHA-256 checksums. builds are unsigned.

## компактная карточка действий

- большое окно заменено компактной чёрной карточкой, раскрывающейся из верхней панели.
- наведи курсор, чтобы увидеть задачу и текущее действие. нажми, чтобы закрепить; закрой, чтобы свернуть.
- план, последние действия и сведения об агентах показаны только при наличии данных Codex.
- запросы разрешений для запущенных здесь задач появляются прямо в карточке с кнопками разрешения и отказа.
- при старте видны только панель и трей. демонстрационные данные остаются явно отмеченными.
- стеклянные настройки из v0.2.0 сохранены.

архивы Linux x64, Windows x64 и macOS universal собираются и тестируются в GitHub Actions. библиотеки Qt включены, контрольные суммы SHA-256 приложены. сборки не подписаны.
