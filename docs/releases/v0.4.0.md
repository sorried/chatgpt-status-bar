## English

- Linux panels on Hyprland can stay above regular windows and across workspaces.
- choose a pill or notch shape and set the panel width and height in Appearance settings.
- other Wayland compositors control stacking and may ignore always-on-top requests.

Linux x64, Windows x64 and universal macOS bundles are built and tested in GitHub Actions. archives include Qt dependencies and have SHA-256 checksums. builds are unsigned.

## Русский

- в Hyprland панель Linux закрепляется поверх обычных окон и на всех рабочих столах.
- в настройках оформления можно выбрать пилюлю или чёлку, а также задать ширину и высоту.
- другие композиторы Wayland сами управляют порядком окон и могут игнорировать запрос «поверх».

Архивы Linux x64, Windows x64 и macOS universal собираются и тестируются в GitHub Actions. Библиотеки Qt включены, контрольные суммы SHA-256 приложены. Сборки не подписаны.
